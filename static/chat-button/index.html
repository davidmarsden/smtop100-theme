For Top 100 managers

Top 100 Chat, while you play

Put a Top 100 Chat button on Soccer Manager. It opens Top 100 Chat in a side window, so the game stays open while you talk to the rest of Top 100.

On a computer: the Chat button (recommended)

1. Install Tampermonkey

Tampermonkey is a free browser extension that runs small scripts on the websites you choose. Install it from your browser's store: Chrome, Brave or Edge, Firefox or Safari.

In Chrome, Brave and Edge, also turn on Allow user scripts (or Developer mode) for Tampermonkey in the browser's extension settings, if it asks.

2. Add the Top 100 Chat button

Click the button below. Tampermonkey opens and shows the script; click Install.

💬 Install the Chat button

3. Play

Open Soccer Manager. A green Top 100 Chat button sits in the bottom-left corner of every page. Click it to open Top 100 Chat in a side window; click it again to bring the window back to the front. The first time, sign in with your Manager Portal email as usual.

The script only adds the button and opens the chat window. It doesn't read or change anything on Soccer Manager. Updates install automatically.

No extension? Use the Chat bookmark

Drag this button to your bookmarks bar. Click it whenever you're playing and Top 100 Chat opens in a side window.

💬 Top 100 Chat

Can't drag it? Bookmark any page, edit the bookmark, name it "Top 100 Chat" and paste this as its address:

javascript:(function(){var w=window.open('https://manager.smtop100.blog/chat','top100chat','popup=yes,width=440,height=780,left='+Math.max(0,screen.availWidth-460)+',top=40');if(w){w.focus();}else{location.href='https://manager.smtop100.blog/chat';}})();

On your phone

Scripts and bookmarks don't work in the Soccer Manager app. Instead, add Top 100 Chat to your home screen and switch between the two:

  1. Open manager.smtop100.blog/chat and sign in.
  2. iPhone (Safari): tap Share, then Add to Home Screen.
  3. Android (Chrome): tap the menu (⋮), then Add to Home screen or Install app.
